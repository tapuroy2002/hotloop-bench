How estimates work

A reference run of every language ships with this dashboard (reference machine). Languages you run here give your machine's speed relative to that run, group by group. A language you can't build here shows its reference time scaled by that ratio.

Estimates are guides, not measurements. Install the toolchain and run it to get a real number.
