Run it on your own computer

This website shows saved results. Running the benchmark needs the small local runner, which can't run on a website. To run it yourself:

  1. Download the project (ZIP) and unzip it.
  2. Install Node.js and, on Windows, Git for Windows (for Bash).
  3. Double-click start.bat (macOS/Linux: node launch.js). The dashboard opens with the Run button working.

Languages you have installed are measured; the rest are estimated. Source code: github.com/tapuroy2002/hotloop-bench

How estimates work

A reference run of every language ships with this dashboard (reference machine). Languages you run here give your machine's speed relative to that run, group by group. A language you can't build here shows its reference time scaled by that ratio.

Estimates are guides, not measurements. Install the toolchain and run it to get a real number.
